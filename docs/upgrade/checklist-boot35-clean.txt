| `modules/interview/service/InterviewSessionService.java` | - | 注入使用 |
| `modules/resume/service/ResumeHistoryService.java` | - | 注入使用 |

| `modules/voiceinterview/handler/VoiceInterviewWebSocketHandler.java` | - | 注入使用 |
| `modules/voiceinterview/service/VoiceInterviewEvaluationService.java` | - | 注入使用 |

**风险分析:**
- Spring Boot 4 仍支持 Jackson (jackson-databind)
- 直接 `new ObjectMapper()` 实例化会使用默认配置，可能与 Spring Boot 自动配置的 JacksonBehavior 不同
- Spring Boot 4 可能改变某些 Jackson 默认配置

**建议:**
- 优先使用 `ObjectMapper` Bean 而不是直接实例化
- 注意 JacksonConfig 中的自定义配置是否需要在 Spring Boot 4 中显式声明
